# ADR-0004: Bez reklam i SDK śledzących w V1

**Status:** Accepted  
**Date:** 2026-10-14

## Context

Gra kierowana jest również do dzieci poniżej 13 lat. Reklamy komplikują polityki i skupiają UX na monetyzacji.

## Decision

V1 jest offline bez AdMob/IAP/analytics/push/logowania. Polityka prywatności i sekcja Data safety po rzeczywistym audycie.

## Consequences

Mniej ryzyk i zależności; brak przychodów z V1. Monetyzacja w przyszłości wymaga osobnego ADR, zgodności Families i aktualizacji deklaracji.

## Alternatives rejected

AdMob od pierwszego dnia — niepotrzebna złożoność, brak dowodu na zgodny UX i sensowny potencjał.
