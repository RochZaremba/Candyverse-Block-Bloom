# Rzeczywiste screenshoty Android

Dwa nieedytowane PNG1080×1920 z finalnego podpisanego APK1.0.0+1:
Home i Game po rzeczywistym placement. Zweryfikowano je wizualnie; figury
mieszczą się w panelach. Przechwycenie przez natywny `adb screencap`,
bez nakładek marketingowych, skalowania ani generowania obrazu.

Szczegóły urządzenia, źródło CI i hashe: [provenance](pl/provenance.json).
To emulator Android7/API24, nie dowód wydajności fizycznego telefonu.
Scenariusz uruchamia produkcyjny entrypoint, bez fixture portfela/wyspy.
